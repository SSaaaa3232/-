# Python Hello World Design

## Goal

Create `hello_world.py` in the workspace root. Running the file prints:

```text
Hello, World!
```

## Design

- Use one Python statement: `print("Hello, World!")`.
- Require no external dependencies or input.
- Keep the example minimal for a beginner.

## Verification

Run:

```bash
python3 hello_world.py
```

The command must exit successfully and print exactly `Hello, World!`.
