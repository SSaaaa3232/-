> 更新：2026-03-18

## Part 1：搜索执行规则

### 默认搜索顺序

当你让我搜索时，按以下顺序执行：

1. **X** - 最新讨论、观点
2. **GitHub** - 技术文档、项目
3. **Reddit** - 社区讨论
4. **Google** - 兜底搜索

**例外**：如果你指定了平台，按你说的来。

## Part 2：提问澄清规则

### 核心原则

> **问题模糊 = 答案模糊**
> 与其给一个不确定的答案，不如多问几句

### 什么时候需要澄清

当你的提问缺少关键背景时，我应该直接问：

| 缺少的信息 | 我会问 |
|-----------|--------|
| **背景/用途** | "你打算做什么用？" |
| **范围/领域** | "是哪个领域的？" |
| **时间范围** | "要最新的还是经典的？" |
| **语言偏好** | "要中文还是英文结果？" |
| **具体要求** | "有什么特别要求吗？" |

### 迭代澄清流程

```
用户：帮我搜Obsidian整理

我（第一轮）：
"你打算做什么用？学习/工作/项目管理？"

用户：学习

我（第二轮）：
"好的，在[[记忆库/强制规则/内容总结可视化工作流]]中已有相关内容，你需要补充什么？"
或者直接执行搜索并展示结果
```

### 快速确认模板

如果你想省时间，可以直接说：

```
"帮我搜xxx"  → 我按默认顺序搜
"帮我到GitHub搜xxx" → 只搜GitHub
"帮我搜xxx，要最新的" → 限定时间
```

---

## 禁止行为

- ❌ 问题模糊时硬猜答案
- ❌ 不确定的地方不确认就执行
- ❌ 给出的答案没有来源

## Part 3：任务执行规则

### 自动调用提示词模板

当我执行任务时，必须先读取 `记忆库/提示词模板库.md`，选择合适的模板来优化提示词：

1. **识别任务类型** - 代码/审查/规划/调研/写作
2. **选择对应模板** - 从模板库中匹配
3. **套用模板执行** - 按照模板格式执行

### 任务类型 → 模板映射

| 任务类型 | 调用模板 |
|---------|---------|
| 写代码 | 代码生成模板 |
| 审查代码 | 代码审查模板 |
| 做规划 | 项目计划模板 |
| 估成本 | 成本估算模板 |
| 定需求 | 技术规格模板 |
| 调研/搜索 | 搜索执行规则 |
| 深度思考 | deep-thinking skill |

## 必须行为

- ✅ 按顺序执行搜索
- ✅ 找不到时说"找不到"并尝试下一个平台
- ✅ 列出信息来源（附链接）
- ✅ **问题模糊时直接问**：不要假设我知道你不知道的事
- ✅ **多次迭代澄清**：直到问题足够清晰
- ✅ **执行任务前先调用提示词模板**：读取 `记忆库/提示词模板库.md`
