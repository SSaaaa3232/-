# 强制规则：外部知识吸收

> 更新：2026-03-17

## 触发条件

- 用户分享文章/视频/链接
- 用户说"看看这个"
- 用户粘贴大段文字
- 用户问如何学习一本书

---

## 核心心法

> **不是问"这本书讲了什么"**
> **而是问"这本书能帮我解决什么问题"**

---

## 6步处理流程

### 1. 选书/选内容验证

在开始阅读前，先验证：

| 验证方法 | 作用 |
|---------|------|
| 看豆瓣/亚马逊评论 | 验证书的质量 |
| 看目录 | 确认有没有你要的内容 |
| 读样章 | 确认适合不适合你 |
| 不适合就放弃 | 不是每本书都要读完 |

---

### 2. 速读定位重点

- **不是从头读到尾**
- **先看目录、序言**
- **确定这本书回答什么问题**

**读书问题模板：**

| 问题类型 | 具体问题 |
|----------|----------|
| 基础问题 | 这本书回答什么问题？ |
| 验证问题 | 作者的论点和我已知的一致吗？ |
| 质疑问题 | 作者的证据充分吗？ |
| 连接问题 | 这个知识和我已有的知识冲突吗？ |
| 应用问题 | 这个能用到哪？ |
| 反例问题 | 什么情况下这个观点不成立？ |

---

### 3. 提取核心观点（3-5个）

每个章节/部分提取一个核心观点，一句话概括。

**筛选标准：**

| 标准 | 问题 |
|------|------|
| 和我有关 | 这个观点能用到哪？ |
| 颠覆认知 | 这个和我以前想的不一样？ |
| 能解释现象 | 这个能帮我理解什么？ |
| 可行动 | 这个能指导我做什么？ |

> **重点不是"漏掉多少"，而是"记住多少"**

---

### 4. 对比分析

| 维度 | 问题 |
|------|------|
| 我有什么？ | 我已经懂什么？这本书验证了我什么？ |
| 我缺什么？ | 这本书补我哪块？ |
| 我能学什么？ | 哪些能立刻用？ |
| 我不需要什么？ | 哪些对我没用？ |

---

### 5. 转化为行动

1-3个可执行改进点：

```
| 要做什么 | 为什么 | 怎么做 | 预期效果 |
|----------|--------|--------|----------|
|        |        |        |          |
```

---

### 6. 记录

#### 情景记忆 vs 语义记忆

| 类型 | 定义 | 存哪 |
|------|------|------|
| 情景记忆 | 具体场景、一次性的经验 | `记忆库/情景记忆/YYYY-MM/` |
| 语义记忆 | 抽象的、可复用的知识 | `知识库/` |

**判断规则：**
- 一次性的感悟 → 情景记忆
- **可复用的观点/金句** → 语义记忆
- 行动清单 → 任务清单

---

## 解决常见问题

### 1. 不知道重点
→ 用"对比分析"：读之前先问"我缺什么？"

### 2. 记不住
→ 用"提取核心观点"：只记3-5个观点，不是整本书

### 3. 用不起来
→ 用"转化为行动"：读完后立刻写"要做什么"

### 4. 担心读错书
→ 用"选书验证"：不适合就放弃

---

## 完整学习流程

```
1. 选书 → 问"我缺什么？"
   ↓
2. 速读 → 看目录、序言，确定重点章节
   ↓
3. 精读重点 → 提取3-5个核心观点
   ↓
4. 对比分析 → 我缺什么？能学什么？
   ↓
5. 转化为行动 → 1-3个立刻能做的事
   ↓
6. 记录 → 写到笔记
   ↓
7. 复习 → 间隔重复
```

---

## 禁止

- 只看不记
- 只记不用
- 照搬照抄
- 从头读到尾（没有重点）
- 担心"漏掉内容"

---

## 关于书籍时效性

| 类型 | 时效性 | 建议 |
|------|--------|------|
| 投资/心理学 | 低 | 经典永不过时 |
| 历史 | 低 | 规律重复 |
| 技术/工具 | 高 | 读新版或网上最新 |

**原则：基础原理不变，变的只是形式。**
