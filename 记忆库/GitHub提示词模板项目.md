## 项目列表

### 1. AI Development Partner ⭐16
🔗 https://github.com/ShaerWare/ai-development-partner

**作用**：把 AI 变成全栈开发团队，包含多重角色

**角色**：
- 系统分析师
- 技术负责人 (Tech Lead)
- 项目经理 (PM)
- DevOps
- 业务顾问

**核心命令**：
| 命令 | 作用 |
|------|------|
| `/c` | 创建完整 CRUD |
| `/tz` | 生成技术规格说明书 |
| `/plan` | 项目计划 + sprints |
| `/cost` | 估算成本和 ROI |
| `/review` | Code Review |
