# 苏格拉底-维特根斯坦-波兰尼思维清洁系统

> 从一个模糊的念头到一个清晰的、可执行的想法。这是一种思维方式，不是一个技巧。
> — @Jaden_riku

## 三层系统

### 第一层：维特根斯坦（扫描）— 发现哪里模糊

**原理**：语言是思想的边界，说不清楚 = 没想清楚。所有复杂表述可以拆解成原子命题。

**工具：命题分解**，将想法拆成三类：
- **F（事实）**：可验证的客观信息
- **D（欲望）**：希望达成的状态
- **Q（困惑）**：自己也不确定的部分

示例："帮我优化一下这篇文章"
→ F: 有一篇已写好的文章
→ D: 想让它变好（但"好"是什么？模糊了）
→ Q: 不确定到底该改什么

**适用**：开口之前，跟任何人说"帮我弄一下"之前先在脑子里拆解。

### 第二层：苏格拉底（挖掘）— 把能说出来的问出来

**原理**：大多数时候你不是不知道答案，只是没被正确问过。通过反诘法将潜意识中的答案"捞出来"。

**工具**：不给答案，只问，问到对方自己把答案说出来。

追问层次：纠结的是两个都好还是两个都差？"转行"是完全放弃还是想同时做？如果无外部压力，你倾向哪个？

**局限**：追到"那种感觉"就到极限了——有些东西怎么追问都说不出来。

### 第三层：波兰尼（感应）— 处理说不出来的默会知识

**原理**：Tacit Knowledge（默会知识）——你明明知道但就是说不出来的知识（厨师的火候、设计师的排版感觉）。认知从大量细碎辅助线索"到"整体判断，这个过程无意识、无法反向拆解（越分析越失稳，如骑自行车）。

**三种提取策略**：
1. **示范**：给一个你觉得"对"的例子 → 从中提取隐含偏好
2. **反面**：说你"不要什么"→ 否定句比肯定句更容易逼出默会知识
3. **行为提取**：拿出你以前满意的作品 → 从过去行为中反向提炼隐含规则

## 完整流程

```
模糊念头
  ↓ 维特根斯坦：拆解 F/D/Q，定位模糊点
  ↓ 苏格拉底：追问，把能说出来的问出来
  ↓ 波兰尼：示范/反面/行为提取，处理说不出来的部分
  ↓
精准可执行的想法
```

## 应用场景

- 写 prompt（在开口之前先拆解自己要什么）
- 做决策（纠结时用追问链）
- 带团队（对方说"你懂我意思吧"时用三种提取策略）
- 对客户需求（拒绝"你懂的"，要例子、反面、过去作品）
