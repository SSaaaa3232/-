# 深度研究两阶段法

> 这两阶段实际上是探索与开发的分离。
> — @hxiao

## 核心模型

2025 年的深度研究：搜索 → 阅读 → 推理 → 重复，每轮都联网。
2026 年的长任务：**两个明确阶段**。

### 第一阶段：Web IO（探索）
- 搜索、阅读、推理
- **目标不是直接给答案**，而是将网络知识具体化到本地文件（.md/.json/.csv）
- 广撒网，建立本地知识库（Data Room）

### 第二阶段：本地循环（利用）
- Agent 挂载本地文件，只对这些文件读取/运行/写入
- **不再发出网络请求**
- 严格、高速迭代

## 为什么切断第二阶段的网络

| 原因 | 说明 |
|------|------|
| **确定性** | 本地文件是不可变快照；网页内容漂移、404、付费墙 |
| **速度** | 文件系统读取毫秒级，网页获取秒级 |
| **一致性** | 交叉核对需在同一知识库操作，否则版本不同 |
| **成本** | 网页 IO 消耗大量 HTML 噪声 token；本地文件已经干净 |

## Data Room 类比

借用 VC 做尽职调查的说法：
- 创始人（你）在第一阶段**准备数据室**
- VC（agent）在第二阶段拿着**固定数据室做尽调**

## 与 LLM Wiki 的关系

LLM Wiki 的 `.raw/` 目录本质上就是一个持久化的 Data Room。每次 Ingest 是第一阶段，每次 Query 是第二阶段的轻量版。
