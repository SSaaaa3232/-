# 强制规则：Obsidian 定期整理自动化

> 更新：2026-03-18
> 触发词：整理、归档、清理

---

## 整理原则

### 定期整理频率

| 频率 | 内容 |
|------|------|
| 每周 | 检查待办、临时文件 |
| 每月 | 归档旧内容、检查重复 |
| 每季度 | 全面审视、调整结构 |

---

## 每周整理任务

### Step 1: 检查临时文件

```
检查：根目录下的临时文件
- 未命名.md → 重命名或删除
- 测试.md → 删除或移到测试文件夹
- *.tmp → 删除
```

### Step 2: 检查任务清单

```
- 完成的任务 → 移到复盘或归档
- 过期的任务 → 删除或延期
- 新任务 → 添加到任务清单
```

---

## 每月整理任务

### Step 1: 归档旧内容

```
归档标准：
- 超过3个月未更新的笔记
- 已完成的项目文档
- 过时的参考资料

归档位置：
- `4-系统/archives/[年份]/`
```

### Step 2: 检查重复内容

```
检查方法：
1. 搜索相似标题
2. 搜索相似内容关键词
3. 合并或删除重复

处理：
- 保留最完整版本
- 其他版本标记为"已合并"或删除
```

### Step 3: 更新索引

```
- 更新 README.md 目录结构
- 更新知识图谱（如果有）
- 检查外链是否有效
```

---

## 每季度整理任务

### Step 1: 结构审视

```
检查：
- PARA结构是否仍然合理
- 是否有新的内容类型需要新文件夹
- 哪些文件夹变得太大需要拆分
```

### Step 2: 规则审视

```
检查：
- 哪些规则不再使用 → 可删除
- 哪些规则需要更新 → 更新
- 是否有新场景需要新规则 → 创建
```

### Step 3: 模板审视

```
检查：
- 模板是否仍然适用
- 是否有新场景需要新模板
- 模板是否需要优化
```

---

## 自动触发条件

以下情况自动触发整理：

1. **每次对话开始时**
   - 检查是否有待归档内容
   - 提示用户需要整理的内容

2. **当文件超过以下数量时**
   - 根目录临时文件 > 3
   - 某文件夹文件数 > 50

3. **用户明确要求时**
   - "整理一下"
   - "归档xxx"
   - "清理重复"

---

## 禁止行为

- ❌ 删除用户可能需要的内容
- ❌ 未经确认删除归档内容
- ❌ 破坏现有链接结构

## 必须行为

- ✅ 每周检查临时文件
- ✅ 每月归档旧内容
- ✅ 定期检查重复文件
- ✅ 更新 README 索引
- ✅ 整理前先备份
