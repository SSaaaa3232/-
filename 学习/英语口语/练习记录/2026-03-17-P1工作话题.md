# 英语口语练习记录

> 日期：2026-03-17
> 场景：P1-4. 工作话题 - 年轻人喜欢的工作类型

---

## 你的回答

1. 在家办公 / 一人创业 (working from home / one-person startup)
2. 因人而异，看专业和兴趣 (depends on different majors and interests)
3. 跳槽只适用于低学历/低价值工作 (job hopping only applies to lower education levels)
4. 年轻人追求自由、独立，想出名 (pursue freedom and independence, want to become famous)
5. AI时代这种现象更普遍 (with AI trend, phenomenon becoming more common)

---

## 纠正与词汇

### 纠正
- "different 专业" → "different majors"
- "job hopping maybe 只针对" → "job hopping might only apply to"
- "low 学历水平" → "lower education levels"
- "low value jobs" → "low-paying jobs"

### 新学词汇
| 中文 | 英文 |
|------|------|
| 专业 | major |
| 兴趣 | interest |
| 追求 | pursue |
| 自由 | freedom |
| 独立 | independence |
| 成名 | become famous / rise to fame |
| 泯然众人 | be ordinary |
| 现象 | phenomenon |
| 越来越常见 | become more and more common |
| 趋势 | trend |
| 随着 | with / following |
