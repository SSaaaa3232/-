# Lint Skill
健康检查：审计 03-wiki 的结构健康度，输出报告并写入 `04-outputs/health/`。

## 触发方式

```
/lint
```
或指定路径：
```
/lint 03-wiki/concepts/AI/
```

---

## 检查项目（逐项执行）

### 1. 孤立页面（Orphan Pages）
- 定义：没有任何页面通过 `[[wikilink]]` 指向它的页面
- 扫描范围：所有 `03-wiki/concepts/` 和 `03-wiki/summaries/`
- 标记：入链数为 0 的文件
- 原因：孤立页面往往意味着概念未被引用，知识在沉睡

### 2. 矛盾页面（Contradictions）
- 定义：两个页面的核心结论相互否定，且无任何一方标注了不确定性
- 检查方式：对比 `## 核心结论` / `## 我的理解` 段落
- 标记规则：若 A 说"应该做 X"，B 说"绝对不能做 X"，且两者都没有 `## 不确定性` 字段 → 矛盾
- 输出：列出矛盾对 + 建议修正方向

### 3. 过时断言（Stale Claims）
- 定义：页面最后一次更新后，同主题的新 source 已 ingest，但该页面未更新
- 检查方式：对比 concept 页面的 `sources:` 中的最早来源日期 vs 页面 `created:` 日期
- 标记：页面声称的结论是否有更新的 source 支持/推翻

### 4. 来源不足的概念卡
- 定义：概念卡片的 `sources:` 少于 2 个
- 原因：单一来源的概念卡说服力不足，可能存在偏差
- 输出：列出来源数 < 2 的概念卡

### 5. 缺失交叉引用
- 定义：两个概念在语义上相关（同属一个顶层分类，或同一 summary 中出现），但双方 `关联概念:` 字段均无对方
- 检查方式：同 summary 的 N 个概念 → 两两检查 `关联概念:` 是否有对方
- 标记：缺少共现链接的概念对

### 6. 空/不完整页面
- 定义：文件存在但正文 < 100 字，或缺少 `## 我的理解` 字段
- 标记：需要补充的概念卡

## 输出格式

```
# 健康检查报告 — YYYY-MM-DD

> 检查范围: ...
> 执行时间: ...

## 检查结果

### 孤立页面
- [文件路径] — 入链数: 0

### 矛盾页面
- [A.md] vs [B.md]: ...

### 过时断言
- [概念卡]: ...

### 来源不足（< 2）
- [文件路径]: 1 个来源

### 缺失交叉引用
- [A] 和 [B] 应互链但缺失

### 空/不完整页面
- [文件路径]: X 字

---

## 建议优先级

| 优先级 | 类型 | 处理方式 |
|--------|------|----------|
| P0 | 矛盾页面 | 立即修正，标注不确定性 |
| P1 | 孤立页面 | 手动补充入链或合并 |
| P1 | 来源不足 | 下次 ingest 同主题时优先补充 |
| P2 | 缺失交叉引用 | 下次 compile 时自动补充 |
| P2 | 空页面 | 补充个人理解 |
| P3 | 过时断言 | 下次 lint 时重新检查 |

---

## 报告写入

- 路径：`04-outputs/health/YYYY-MM-DD-健康检查.md`
- 写入后追加到 `03-wiki/log.md`：
  ```
  ## [YYYY-MM-DD] lint | 健康检查完成
  - 操作人: AI
  - 发现问题: P0: N, P1: N, P2: N, P3: N
  - 报告: [[04-outputs/health/YYYY-MM-DD-健康检查]]
  ```

## 建议频率

每月执行一次，或 wiki 规模每增长 ~20 篇新 summary 后执行一次。
