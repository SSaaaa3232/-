# 强制规则：自我反思与错误记录 + 自动优化复盘

> 更新：2026-03-18
> 整合：错误记录 + 成功后自动优化

---

## Part 1: 成功后自动反思优化（每次对话结束前）

### 触发条件

每次成功完成任务后，在回复用户前**自动执行**反思优化。

### 反思问题清单

每次对话结束前，问自己：

| 问题             | 行动       |
| -------------- | -------- |
| 这次有什么做得好？      | 记住这个方法   |
| 有什么可以优化？       | 思考改进空间   |
| 学到了什么新东西？      | 提取成经验    |
| 规则需要更新吗？       | 判断是否需要补充 |
| 下次遇到类似问题怎么做更好？ | 总结最佳实践   |

### 优化动作

1. **经验提取**
   - 这次成功用了什么方法？
   - 有什么技巧可以复用？

2. **规则检查**
   - 现有规则是否覆盖了这个场景？
   - 是否需要补充新规则？
   - 是否有规则需要修改？

3. **更新规则**
   - 如果发现规则需要更新，立即更新
   - 更新后记录变更内容
   - 推送到 GitHub

4. **记录复盘**（可选）
   - 如果是重要经验，记录到 `4-系统/自我复盘/`
   - 格式：`[日期]-[主题]-复盘.md`

---

## Part 2: 错误反思（出错时）

### 触发场景

- 我犯了错误
- 用户纠正了我
- 某个方法不奏效
- 遇到困难/失败

---

### 反思流程

#### 1. 错误识别

当我发现错误时，主动记录：
- 什么错了？
- 为什么错？
- 怎么发现的？

#### 2. 原因分析

- 是信息不足？
- 是假设错误？
- 是方法不对？
- 是理解偏差？

#### 3. 改进方案

- 以后遇到类似问题怎么做？
- 需要补充什么规则？
- 需要问用户什么信息？

#### 4. 记录归档

记录到：`4-系统/自我复盘/`

格式：
```
## [日期] 错误复盘

### 问题
[描述问题]

### 原因
[为什么会错]

### 改进
[以后怎么做]
```

---

## 必须行为

- ✅ 成功后自动反思优化
- ✅ 犯错后主动复盘
- ✅ 记录错误原因
- ✅ 提出改进方案
- ✅ 提取成可复用的规则
- ✅ 规则更新后推送到 GitHub

## 禁止

- ❌ 对话结束前不反思
- ❌ 犯错后不承认
- ❌ 同一错误重复犯
- ❌ 只说"对不起"不改
- ❌ 发现规则需要更新但不更新
