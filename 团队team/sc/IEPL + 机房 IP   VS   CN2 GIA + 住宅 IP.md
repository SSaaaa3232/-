# 精华理由：

- 目前的情况是，前有国外 AI 封号，后有国内 IEPL 封杀、大规模整顿。可以说是一根筋两头堵。用 AI 吧，国内的豆包又是个智障；不用 AI 吧，感觉生活都无法过下去了。

# 检测手段

- IP（最重要的基础，但 IP 确实不是唯一的因素）
- 
- **WebRTC 暴露**
	- 可以进行穿透检测真实 IP（Clash 开启虚拟网卡就可以避免
- 
- **DNS 泄露**可以检测这次访问通过哪些 DNS 服务器查询域名地址，如果在国内进行过查询就泄露了
	- （Clash 开启全局模式就可以避免，检测结果中只要没有中国大陆和香港就可以了）；

- **浏览器指纹识别**会综合设备、屏幕、浏览器信息生成相对高唯一性的哈希值。
	- （不要使用浏览器，下载本地 **ChatGPT、Claude 应用**就可以解决。）这个很重要，因为爬虫等很多都是用模拟浏览器访问的无头浏览器进行滥用，换成 Desktop 应用后，风控就会降低很多，**Cookies 和跟踪器**也不用担心了。

- 电脑的时区和语言
	- 改成美国和英语就好了。如果之前被封过号，建议清除之前的浏览器记录，并删除之前的应用后重新下载，避免关联。注册新的账号，然后可以使用外区苹果 / 谷歌礼品卡充值，闲鱼 / 京东上都有卖的。
	- 最后确保 IP 可以稳定纯净，这不是唯一的因素，但却是最基础的。不要暴露在机房 IP 上就可以了。很多时候本来用普通机场，不小心手滑打开了 ChatGPT，结果很多时候不小心打开了一次就被降智了。


# 现状：

- 一些最火的深港三网优化线路也无法使用了，很多线路都被关闭，系统也必须换成新的系统。结果就是大量节点无法使用，用户全都涌到其余极少数几个能用的节点，把带宽占满了，结果就是非常卡，甚至几乎无法使用。

- 国内对于 IEPL 开始了大规模整顿。据我所在的某个头部 IEPL 线路转发面板群中看到的，目前已经不接任何个人新用户了，之前的线路也要大规模涨价，

- 以前没有这些花里胡哨的，就是便宜量大的 IEPL 机场，没人在乎什么机房 IP，访问 YouTube 看视频和 X 刷贴也没有什么限制。

- 开始需要住宅 IP，是从爬虫开始的，然后是跨境电商，最后是访问 AI。

# 概念解释：

- 线路
	- 主要有两种：IEPL 和 CN2。（高级的线路）
	- 虽然国内还没有成为超级局域网，但是访问世界互联网的时候，在出口会比较堵。有些能访问但有点慢的国外大学教育网站之类的，就是这个原因。

- IEPL 线路
- 
- 简单理解就是从深圳到香港有一条企业专线，专门的网线，可以绕过出口，所以就不会堵了，但现在一些专线本身被取消了。

- CN2线路
- 
- CN2 就是走出口，但走的都是最高端、优先级最高的出口，流量都堵在下面了，CN2 从最上面轻松飘过，所以也不会卡。CN2 除了原本的含义，一般也泛指三网都会优化；
- 
- 如果加上 GIA，就是到了国际互联网优先级也是 Tier 1。所以香港、新加坡、日本用 IEPL 更快；美国、欧洲 CN2 GIA 远一点反而更有优势，也不用担心省级的限制。
