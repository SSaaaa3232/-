## 四、1小时高效学习法

### 核心：闭环学习

```
┌─ 10分钟 ─┐
│  学新东西  │ ← 带着问题学
└────┬─────┘
     ↓
┌─ 30分钟 ─┐
│  实践/记  │ ← 用自己的话记笔记
└────┬─────┘
     ↓
┌─ 20分钟 ─┐
│  复盘输出 │ ← 写心得/讲给别人听
└──────────┘
```

### 具体做法

| 10分钟   | 30分钟   | 20分钟  |
| ------ | ------ | ----- |
| 带着问题学  | 边学边记笔记 | 写3个收获 |
| 查目录/大纲 | 重点画出来  | 1个行动点 |
| 明确学什么  | 关联已有知识 | 1个疑问  |

## 五、复习安排（间隔重复）

### 黄金复习时间点

| 学完后  | 复习什么        |
| ---- | ----------- |
| 当天晚上 | 翻一遍笔记（10分钟） |
| 3天后  | 写心得/讲出来     |
| 1周后  | 复习笔记+行动检查   |
| 1个月后 | 整体回顾        |

### 具体复习时间

| 时间   | 内容           |
| ---- | ------------ |
| 每天早上 | 复习昨天笔记（10分钟） |
| 每周日  | 本周复盘（30分钟）   |
| 每月月底 | 月度回顾         |

> **少量多次 > 一次长时间**
