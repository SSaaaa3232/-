# key

你这几轮提问——hook、权重、redline、然后让我停下来总结——本身就是最强的那层防御。自动化能降低你 audit 的频率，但替代不了你 audit。这不是让你负担变重的说法，是说：你保持"偶尔追问一句"的习惯，比我塞十条 CRITICAL 有用。

# 思考
怎么实现绕开成本比老实做要高

怎么实现将我在编排过程中做的事担任的角色降到最低

将一下人工决定自动化

|     |                                         |
| --- | --------------------------------------- |
| A   | 跳步 → 层 4+5+7 组合（产物驱动 + 脚本检查 + 给人看）      |
| B   | 假完成 → 必须贴命令输出；"跑通了"这句话独立成消息不够，要带 output |
| C   | 假阅读 → 读完立刻让我复述文件内容；或问具体行号的问题            |
| D   | 早熟判断 → 要求区分"我查过的"和"我推断的"；每句都加来源标注       |
| E   | 阻力最小 → 开工前先让我口述方案并对比至少一个替代，选中的要说明为什么    |
