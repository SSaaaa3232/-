# Perplexity 深度论文搜寻提示词

> **用途**：使用 Perplexity AI 进行精准文献检索，为 Trends in Biotechnology 综述提供文献支撑  
> **细分领域**：精准氧化还原工程（Precision Redox Engineering）——辅因子特异性改造与动态调控策略在代谢工程中的应用  
> **检索目标**：近五年高影响力论文 + 奠基性高引经典文献

---

## 细分领域定位

| 层级 | 内容 |
|------|------|
| **一级学科** | 代谢工程 / 合成生物学 |
| **二级细分** | 辅因子工程（Cofactor Engineering）中的 NAD(P)H 特异性改造与动态氧化还原调控 |
| **交叉方向** | 计算酶学 + 动态代谢工程 + 正交生化系统 |
| **目标期刊** | Trends in Biotechnology（目标投稿期刊） |

## 提示词一：近五年高影响力综述与研究论文

```
请帮我系统检索近五年（2020-2025）在精准氧化还原工程与辅因子工程领域的高影响力学术论文。

检索关键词组合：
- 英文核心词：precision redox engineering, NADH NADPH cofactor engineering, metabolic engineering redox balance, dynamic metabolic regulation cofactor, orthogonal redox cofactor
- 进阶词：enzyme cofactor specificity engineering, directed evolution NADPH preference, redox sensor-regulator circuit, noncanonical nicotinamide cofactor, synthetic redox metabolism
- 应用场景：high-value chemical biosynthesis, microbial cell factory, biomanufacturing

具体检索目标：
1. 近五年发表在 Nature Catalysis、Nature Communications、Metabolic Engineering、Current Opinion in Biotechnology、Trends in Biotechnology、Biotechnology and Bioengineering、Metabolic Engineering Communications 上的综述（Review）和研究论文（Research Article）
2. 特别关注以下方向的论文：
   - NADH/NADPH 特异性改造（定向进化 + 计算设计）
   - 动态传感与调控系统（metabolic sensor, responsive gene circuit, dynamic metabolic engineering）
   - 正交/非天然辅因子系统（orthogonal redox cofactor, noncanonical NADH, synthetic electron carrier）
   - 系统代谢工程中的辅因子平衡（genome-scale model, redox flux analysis, NADH NADPH compartmentalization）

请按期刊、发表年份、研究方向分类列出，并提供每篇的标题、作者、期刊、年份、DOI 和一句核心贡献描述。

同时请标注哪些论文使用了机器学习/AI 辅助的辅因子工程设计。
```

## 提示词二：奠定领域基础的经典高引文献

```
请帮我检索奠定"氧化还原辅因子工程"或"精准代谢工程中的辅因子调控"这一领域基础的经典高引文献。

检索策略：
1. 使用 Google Scholar 或 Web of Science，搜索以下核心文献类型：
   - "Redox cofactor engineering" metabolic engineering 综述
   - "NADPH" OR "NADH" "cofactor engineering" metabolic engineering
   - "Dynamic metabolic engineering" redox balance
   - "Orthogonal redox cofactor" biocatalysis

2. 重点检索被引量 ≥ 200 次（Google Scholar）的奠基性论文，包括但不限于：
   - 该领域的首篇/早期系统综述
   - 提出关键方法或概念的核心论文（如：定向进化改造辅因子特异性的里程碑论文）
   - 动态代谢工程或响应型调控系统的开创性工作
   - 正交辅因子系统的早期验证性研究

请列出：
- 论文标题、全部作者、发表期刊、年份
- Google Scholar 被引次数
- 该论文的核心贡献（一句话）
- 为什么它是奠基性文献（与当前研究领域的关联）

如果同一方向有多篇奠基性论文，请按时间线（从最早到最新）排序，并标注哪些已被你的论文草稿引用。
```

## 提示词三：针对论文三大策略分别检索

```
请分别针对以下三个细分方向，各检索 5-8 篇近五年高影响力论文：

方向 A - 辅因子特异性改造（Cofactor Specificity Engineering）：
检索词：NADPH specificity mutation, NADH preference engineering, directed evolution cofactor, enzyme engineering NAD(P)H, computational design cofactor binding

方向 B - 动态传感与氧化还原调控（Dynamic Redox Sensing & Regulation）：
检索词：NADH sensor circuit, redox-responsive gene circuit, dynamic metabolic engineering, growth-coupled product formation, adaptive regulation biocatalysis

方向 C - 正交氧化还原辅因子（Orthogonal Redox Cofactors）：
检索词：orthogonal nicotinamide cofactor, noncanonical NADH, synthetic redox carrier, cell-free biocatalysis cofactor regeneration, orthogonal enzyme evolution

对每个方向，请输出：
- 按发表年份降序排列的论文列表（标题、作者、期刊、年份、DOI）
- 每篇论文的核心发现/方法（1-2 句）
- 该方向的代表性研究团队（如 Prather、Keasling、Bennett、Xiao 等实验室的工作）

最后请综合三个方向，给出一份"领域现状地图"——指出哪些方向已相对成熟，哪些仍是前沿开放问题。
```

| 步骤  | 优先级  | 提示词  | 目的                       |

| 1   | 🔴 高 | 提示词二 | 找到奠基性文献，确保综述有历史纵深        |
