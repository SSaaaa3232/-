## 总结

**核心观点：** 不追风口，不玩概念，靠收购"无聊"的本地小生意积累财富。

**来源：** 《主街百万富翁》(The Millionaire Fastlane)

---

## 什么是"无聊生意"？

**四个特征：** 陈旧、老旧、薄弱、简单

| 例子 | 说明 |
|------|------|
| 洗衣店 | 白领看不上的生意 |
| 洗车店 | 现金流最稳定 |
| 屋顶维修 | 刚需、抗衰退 |
| 油漆公司 | 估值低、竞争少 |
| 园林绿化 | 蓝海市场 |

---

## 为什么收购？

### 1. 时机绝佳
- 美国正经历小企业主退休潮
- 子女不愿接手家族生意
- 大量赚钱企业被迫关门
- **买家有极大谈判空间**

### 2. 现金流从第一天就有
- 接手当天就在赚钱
- 买的不是希望，是现成的现金流

### 3. 活得久（林迪效应）
- 经营5年以上的企业
- 存活率是初创公司的2-3倍
- 买的不是彩票，是确定性

### 4. 抗衰退
- 洗衣、修车、通下水道 = 刚需
- 经济差也得用

### 5. 没人抢
- 不够"性感"，VC和创业者看不上
- 估值低、性价比高

---

## 如何选择？

### 黄金法则：看结构，不看热爱

| 要看 | 不要看 |
|------|--------|
| 现金流 | 个人喜好 |
| 利润模型 | 情怀 |
| 客户复购 | 感觉 |
| 风险 | 热爱 |

**例子：** 喜欢喝咖啡 ≠ 应该开咖啡馆

## 发展四阶梯

| Level | 状态 | 目标 |
|-------|------|------|
| L1 | 业余试水 | 洗衣店、自动售货机（每周10-30小时） |
| L2 | 全职CEO | 承包商、清洁服务（花钱买工作） |
| L3 | 中层管理 | 20-50人团队（招总经理替你管） |
| L4 | 市场领导者 | 多家企业，高价卖出 |

## 核心思维

> 真正的财富不靠卖时间，靠拥有资产。

**不需要有钱，需要会借钱：**

| 方法 | 说明 |
|------|------|
| 银行借款 | 好项目 + 良好信用 = 金融机构愿意出资 |
| 卖家融资 | 付10%-50%首付，用企业未来3-10年利润分期支付 |
| OPM | 用别人的钱（Other People's Money） |
