# 📎 附录：相关概念

### 经典例子

**马斯克造火箭**：
- 传统思维：火箭很贵，所以发射火箭很贵
- 第一性原理：火箭由什么材料构成？材料成本是多少？能否大幅降低？

### 三步法

1. **拆解**：把问题拆到最基本的事实
2. **追问**：问"为什么"
3. **重建**：从基本事实重新构建方案
