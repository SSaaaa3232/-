# 🎯 读前准备

## 这本书解决什么问题？

1. 什么是系统思考？
2. 如何识别和应用系统中的反馈环路？
3. 如何避免头痛医头、脚痛医脚的线性思维？

## 预测：作者核心观点可能是？

1. 整体大于部分之和
2. 系统行为源于反馈结构
3. 杠杆点在于理解系统的根本结构

# 📚 读书流程

## 1. 读的时候

- 用手机/iPad 批注
- 或用 Excalidraw 划线
- 或记录闪卡笔记（见下方格式）

## 2. 读的时候 - 提问法

### 分块提问（每章/每部分）

每个部分提3-5个问题：
- **事实理解**：作者说了什么？
- **原因分析**：为什么这么说？
- **个人关联**：与你有什么关系？

### 整体提问（全书完成后）

- 核心观点是什么？
- 你认同吗？为什么？
- 还能应用在哪些场景？

## 3. 读完后 - 整理成笔记

用本模板整理

## 4. 复习 - 闪卡

用 obsidian-spaced-repetition 插件复习

# 📎 附录：高手玩法

### Atomic Notes
每条笔记只记一个知识点，原子化

### 双向链接
书 → 概念 → 其他书，形成知识网

### 间隔复习
用闪卡复习书中的关键概念
