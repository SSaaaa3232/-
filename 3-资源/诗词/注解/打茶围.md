# 打茶围

> 更新：2026-03-19

---

## 含义

**打茶围**是古代的一种社交活动，指男性到青楼或茶馆喝茶、聊天、听曲。

- **打**：进行、做的意思
- **茶围**：喝茶的聚会/场所

---

## 背景

| 时期 | 形式 |
|------|------|
| 清朝/民国 | 男性文人雅士到青楼茶馆 |
|  | 喝茶、听曲、看姑娘 |
|  | 是一种社交娱乐方式 |

---

## 演变

- 早期：纯喝茶听曲的文雅活动
- 后来：逐渐变成青楼的代称
- 现代：较少使用，多出现在影视/文学中

---

## 例句

- 旧时文人最喜欢打茶围，一边喝茶一边听曲。
