FateTell，5 个人的团队，用八字给海外用户算命。一份命书定价 $39.9，据创始人公开分享，复购率 38.7%——做过消费品的人知道这个数字意味什么，很多品牌拼死拼活也就 20% 出头。七成收入来自订阅，甚至成了刚需复购类型的需求。

这不是个例。海外 Starla 上线几个月，靠 TikTok 传播起来，单月峰值日收入 12.4 万美元，总营收超 250 万美元。印度占星平台 Astrotalk 更夸张，2025 财年营收超 10 亿人民币，同比增长 85%。"人生 K 线图"那个项目把八字量化成股票 K 线，单条浏览量 323 万，服务器直接挤爆。

说实话，我最初也觉得这就是玄学。后来拿自己和身边人的八字排了一圈，大方向上的准确率有六七成，让我震惊——这个后面详细说。

钱也是真的。这门生意成立的原因很简单：AI 出一份命理报告的成本趋近于零，而焦虑是反复发作的——事业不顺算一次，感情出问题再算一次，年末又想看明年运势。更关键的是，没人会把理财 App 的年报截图发朋友圈，但 AI 给你算出来一张命盘图，你大概率会截图发出去。

供给成本归零、需求反复发作、传播靠用户自发——三个变量同时成立的生意不多。全球占星 App 市场今年估值 56.9 亿美元，到 2030 年预计翻到 117 亿。国内同样的东西卖 9.9 元，出海卖 9.9 美元，毛利差七倍。

**但大多数 AI 算命产品活不过三个月。**

## 为什么活不过三个月

赛道好，不代表随便做就能赚钱。

你把八字发给 ChatGPT，出来的是什么？"事业有贵人相助""财运先抑后扬""婚姻宜晚不宜早"。正确的废话——每个人都适用的话等于什么都没说。用户试一次就知道不准，不会有第二次，更不会有 38.7% 的复购率。

一条提示词调用的只是 AI 的通用知识。它知道五行生克是怎么回事，但不知道《穷通宝鉴》里戊土生在申月调候该怎么取，不知道梁湘润的生旺库凶年怎么判，不知道袁树珊的十六字法怎么排流月。

更致命的是排盘错误。我在实际使用中碰到过：

- 巳丑被判成半合金。梁湘润明确规定半三合必须带子午卯酉（四正位），巳丑不带，不算。一个半合判错，整盘定性全变
- 流月评级直接反转两级。本该标"高危"的月份被标成"平稳"
- 大运被截看。"上五年看天干，下五年看地支"——任铁樵在《滴天髓》里明确反对这种做法

这些错误的共性：AI 没读过原典，凭通用知识套公式，遇到细节就翻车。用户第一次可能看不出来，但连续用两三次就会发现前后矛盾。然后就再也不来了。

复购率 38.7% 的前提不是营销做得好，是东西真的有点准。我自己的体验也是这样——发现它不是在说废话之后，就会忍不住继续用。

## 我做了什么

我想搞清楚一件事：如果让 AI 真正读完经典原文，而不是靠通用知识瞎套，八字到底准不准。

于是用 Claude Code 通读了三十多部命理经典，搭了一个 44MB 的知识图谱，最后做成了一个一键安装的 Claude Code Skill。

典籍数字化

这不是找几本电子书丢给 AI 的工作。这些典籍里大部分只有影印版扫描件，市面上没有现成电子文本。有些是民国时期竖排繁体，OCR 识别率很低，扫出来错字漏字一堆，必须拿着原始扫描件逐段逐字校对。

安装包里分发了 17 部公共领域典籍：八字方向 13 部，包括《子平真诠》《滴天髓阐微》《穷通宝鉴》《三命通会》及徐乐吾四注本等；紫微方向有明道藏版《紫微斗数全书》；另有袁树珊两部、六壬一部。完整书单在安装包 README 里。

梁湘润全套、韦千里三部、吴俊民等当代名家著作受版权保护，不在包里分发——但我通读后提炼的方法论笔记在包里。这些笔记是 AI 排盘时的操作手册。

每本逐字读完写笔记。命理学的规则散在几十部著作里，同一个概念在不同作者手里经常互相矛盾，不全部读通你根本分不清谁对、在什么条件下对。9 篇核心笔记写了十五万多字。

排盘流程

拿到一个人的出生时间，系统走十五步完整流程。

先做基础工程：把阳历出生时间转成真太阳时（不同城市有经度差，不校正可能差一个时辰，整盘直接排错），排出四柱八字，列藏干，排命宫，判断日主强弱。

然后进入核心分析：查《穷通宝鉴》看这个日干在这个月份需要什么调候（冬天寒水需要火暖局，夏天燥土需要水润局），取格局（月令本气是否透干，决定了整盘的结构），确定用神喜忌。这几步是命理学最难的部分，不同流派分歧最大。

所以从这里开始四家并行投票。不是随便挑四家——最初试过更多，但发现有些方法之间高度重叠，比如任铁樵和徐乐吾的方法论基础一致，同时用等于投了两票给同一个人。筛下来方法论差异最大、覆盖维度互补的四家：

![[ce5ad0365907a97b741a1016b2d2f296_MD5.png]]

四家各自独立跑完，四家一致 = 高置信度，三家一致 = 中置信度，两两分歧 = 低置信度，标出来等验证。逻辑和机器学习的 ensemble voting 一样——单模型准确率有限，多模型投票后显著提升。

最后叠一层八字和紫微斗数的双系统交叉验证。八字看天干地支（时间维度），紫微看十二宫星曜（空间维度），两套完全独立的系统在财运、事业、婚姻、健康等维度上对照——两套都指向同一个结论才算可信，矛盾的重新检查。

整个流程贯穿几条铁律：禁止蒙猜（不知道就说不知道）、禁止反推（不能拿已知事实凑解释，先盲排再验证）、禁止截看大运（天干地支不可割裂）、半三合必须带子午卯酉（市面上绝大多数工具都判错这条）。违反任何一条，分析结果直接作废。

## 拿邵逸夫的八字跑一遍

光说方法论没用，看系统实际排出来什么。邵逸夫，1907 年 11 月 19 日辰时，浙江宁波，107 岁，华人娱乐业教父。

系统排出四柱：

![[0920726659883f0748956ad1a20deb1c_MD5.png]]

壬水生在亥月，得令通根，身强偏旺。月令比肩不取格，食神透时干、正财透年干 → 食神生财格。查《穷通宝鉴》壬水亥月需丁火调候，恰好年干就是丁火。基础分析没什么争议，四家一致。

**真正的发现从天干链条开始。** 四个天干形成一条完整的生克链：

辛(印) → 壬(身) → 甲(食神) → 丁(正财)

印生身，身生食，食生财，四环一气贯通，没有一环是断的。翻译成人话：别人给他资源（印生身）→ 他转化成作品（身生食）→ 作品变成钱（食生财）。做电影赚钱 → 赚了钱投入做更多电影，飞轮天生就是通的。

**更深一层：丁壬合木化喜。** 年干丁火和日干壬水天干相合，合化木——木在这个盘里是食伤，是喜神。别人的盘经常是财来合身化忌，钱来了反而往坏方向拉。邵逸夫正好反过来：钱来了 → 变成创作力 → 创作力又变成更多的钱。财富良性循环，越转越快。

**地支无冲无刑无害。** 未亥申辰之间没有任何激烈的对抗关系，一辈子没有大的剧烈波动——活到 107 岁，地支写得清清楚楚。

再看大运，对照邵逸夫的人生轨迹：

![[5ff3a8935fddb4369d35c2cc9a788198_MD5.png]]

34 到 73 岁，连续 40 年财运和食伤运，对应的恰好是从建立邵氏到 TVB 称霸香港的全盛期。

这些分析全是系统先盲排出结论，再对照史实验证的——排出四环链条和丁壬合木，然后去查他的生平。盘面结论和历史事实完全吻合。验证不通的，改框架，不硬解释。

邵逸夫是公众人物，生平资料公开，你可以说这是事后对号入座。所以我做了另一件事：拿自己、家人和朋友的八字盲排——不提供任何背景信息，只给出生时间和地点，看系统排出来什么。大方向的命中率确实在六七成左右。有些结论排出来的时候我觉得不靠谱，去跟当事人核实，发现真的对上了。一个学数据科学的 02 年理工生告诉你八字有六七成准，我自己说出来都觉得离谱，但反复测下来就是这样。

## 怎么用

两种方式，按你的需要选。只想体验一下的，复制提示词发给任何 AI 就行。想要完整系统的，装 Claude Code Skill，17 部公共领域典籍、9 篇方法论笔记和知识图谱全在里面。

方法一：升级版提示词（所有 AI 都能用）

直接复制发给 ChatGPT、Claude、DeepSeek 都行。比市面上流传的版本多了四家投票和验证机制：

> 你是一位精通中华传统命理学的专业研究者。你的分析必须同时运用四家方法，通过投票机制确定共识结论： 四家方法： 1. 徐乐吾法：格局为核心，调候为急时压过格局。参考《子平真诠》《穷通宝鉴》 2. 梁湘润法：五道筛子排序（生旺库凶年 > 天罗地网 > 伏吟反吟 > 日犯岁君 > 格局喜忌）。参考《子平基础概要》《子平教材讲义》 3. 袁树珊法：排命宫 + 排小限 + 十六字法（四柱8字 + 命宫2字 + 小限2字 + 大运2字 + 流年2字 = 16字全盘）。参考《命理探原》 4. 韦千里法：八步断命法 + 大运转角论。参考《八字提要》《千里命稿》 铁律（违反任何一条 = 分析无效）： - 禁止蒙猜：不确定就说"不确定"，不要硬给结论 - 禁止反推：不能用已知事实倒推解释，先盲分析再验证 - 禁止截看大运：天干地支不可割裂 - 半三合必须带子午卯酉（四正位）：巳丑、寅戌、卯未都不算半合 - 每个结论标注出处（哪家方法、什么规则） 请根据我提供的信息分析： 【个人信息】 出生日期（阳历）： 出生时间： 性别： 出生地： 【分析流程】 1. 排四柱（含真太阳时校正）+ 列藏干 + 排命宫 + 排大运 2. 识日主（参照《滴天髓》十干论） 3. 月令 + 强弱 + 格局 + 调候（查《穷通宝鉴》该日干该月份） 4. 四家分别独立分析，各自给出结论 5. 投票共识：四家一致=高置信度，三家一致=中置信度（标注少数派警告），两两分歧=低置信度 6. 先预测过去已发生的关键事件（标注年份和年龄），用于验证分析框架是否成立 7. 验证通过后，分析未来大运流年走势和关键年份 8. 总结：命局核心特点、最大风险、最佳方向、最值得把握和最需要小心的年份

填入你的信息发出去就行。它不是让 AI 随便聊聊八字，是强制按四家方法并行分析再投票，每条结论有出处和置信度。

方法二：装 Claude Code Skill（完整系统）

提示词是让 AI"假装"懂命理——给它一套规则，靠它自己的通用知识去套。Skill 性质完全不一样：17 部典籍原文和 9 篇方法论笔记全在包里，AI 排盘的时候是真的在翻书找原文出处。

整个安装包 59MB（zip），解压后 61 个文件。包里有 17 部公共领域典籍（按八字/紫微/袁树珊/六壬分好目录），还有这些东西：

**9 篇核心方法论笔记，十五万多字。** 每部经典逐字读完之后写的方法论提炼。徐乐吾四书笔记把《子平真诠》《滴天髓》《穷通宝鉴》《造化元钥》的核心框架提炼到一份文档里；梁湘润三篇分别对应基础概要、教材讲义、神煞探原；另有十五步排盘完整流程、紫微斗数概要、认识论框架、工具书速查索引、RAG 使用指南。这些笔记是 AI 排盘时的操作手册——先查笔记定框架，遇到细节再翻原典找出处。

**名人命例。** 邵逸夫、毛泽东、张学良等完整案例分析，每个先盲排出结论再对照史实验证。另有韦千里《呱呱集》28 人索引可以当练盘素材。

**44MB 知识图谱。** 45,895 个实体、108,184 条关系。构建过程是把典籍切成几千个文本片段，每个片段过两轮 LLM 抽取（第一轮提取实体和关系，第二轮查漏补缺），再跨片段去重合并，最后人工清洗——同一个概念在不同典籍里叫法不同，机器分不清，得手动合并。

图谱最大的价值是跨书检索——你问"武曲化忌怎么解"，它能同时从多部典籍里把所有相关段落拉出来对比。手动翻书翻到什么时候，图谱几秒钟搞定。

安装

解压后跑 ./setup.sh，按提示选模式：

**Level 1（轻量，零依赖）**——Claude Code 用自带的文件读取工具直接查原典文本。不需要装额外东西，不需要 API key，一条命令装完。大部分人用这个就够了。

**Level 2（高级，含知识图谱）**——44MB 图谱注入本地 LightRAG，支持跨书语义检索。需要额外装一个工具包和一个 LLM API key。经常排盘或做深度研究的人装这个。

两种模式不冲突，可以同时用。

## 边界

梁湘润说得最直接："命理大约只有百分之六、七十的或然律。"

我实测下来，这个数字基本成立。同一个八字在不同城市、不同家庭、不同时代，具体走向可以差很多。八字描述的是潜力空间和风险窗口，不是剧本。凡说"百分百准"的，都是骗子。

但六七成够用了——至少我现在看流年会多留一个心眼，身边人问我我也会帮他们排一下。
