# skills是什么

- 文件夹

>打包了可组合程序性知识的文件集合

- 优势
	- 集成脚本（当作工具）
	- 随时修改
	- 保持一致性和效率：统一代码风格和工程规范
	- 更好使用第三方产品
	- 记忆变的具体可迁移（高效复用）

- MCP对比：

	- 没办法修改工具本身
	- 占上下文影响token

## MCP优势互补

- 编排多个MCP工具串成复杂的工作流
- MCP：提供与外部世界的连接（API、数据库、第三方服务）
- Skills： 提供在这些连接之上的专业知识
- 垂直领域：比如：金融服务和生命科学（MCP和skills）

## 思考方向

- 测试和评估
	- 确保 Agent 在正确的时机加载正确的 Skill，并且输出质量达标
- 版本管理
- 依赖声明
	- Skills 之间可以互相引用，也能声明对 MCP 服务器和环境包的依赖。这会让 Agent 在不同运行环境中的行为更可预测

ps:

- git:管理版本
	- Skill 演变带来的 Agent 行为变化需要清晰追踪
- Drive：共享
- zip：打包发团队
