# 艾宾浩斯记忆曲线

> 更新：2026-03-19

---

## 核心原理

遗忘曲线表明：学习后如果不复习，记忆会快速衰减。

```
时间    | 记忆保持率
────────┼──────────
20分钟后 | 58%
1小时后  | 44%
1天后    | 33%
2天后    | 28%
6天后    | 25%
31天后   | 21%
```

---

## 复习时间点（黄金节点）

| 学完后 | 复习时间 | 记忆保持 |
|--------|----------|----------|
| 第1次 | 当天（20分钟内）| ~100% |
| 第2次 | 第2天 | ~80% |
| 第3次 | 第4天 | ~60% |
| 第4次 | 第7天 | ~50% |
| 第5次 | 第15天 | ~40% |
| 第6次 | 第30天 | ~30% |

---

## 具体应用

### 你的复习安排

| 学习内容 | 第1次 | 第2次 | 第3次 | 第4次 |
|----------|-------|-------|-------|-------|
| 英语单词 | 当天晚上 | 第2天 | 第4天 | 第7天 |
| 投资笔记 | 当天晚上 | 第3天 | 第7天 | 第15天 |
| 街霸问题 | 每次练习前 | - | - | - |
| 书籍笔记 | 3天后 | 1周后 | 1个月后 | - |

---

## 实际操作

### 方法1：当天复习（最重要！）

- 学完英语后，**当天晚上**翻一遍笔记
- 学完投资后，**当天晚上**写心得

### 方法2：制作复习卡片

```
正面：问题/概念
背面：答案/解释

复习时先看正面想答案，再看背面验证
```

### 方法3：设置提醒

| 内容 | 提醒时间 |
|------|----------|
| 英语单词 | 每天早上8:00 |
| 投资笔记 | 每天晚上19:00 |
| 街霸问题 | 每次练习前 |

---

## 对应你的时间表

```
早上 8:00-8:10   → 复习昨天英语单词
                  → 复习昨天投资笔记

晚上 18:00-19:00 → 今日复盘
                  → 翻今天学的笔记

周日 30分钟       → 本周复习
                  → 检查艾宾浩斯节点
```

---

## 简化版（适合懒人）

如果记不住复杂的时间表，记住**最核心的3个节点**：

| 复习 | 什么时候 |
|------|----------|
| 第1次 | 当天晚上 |
| 第2次 | 3天后 |
| 第3次 | 1周后 |

**能做到这3次，记忆效果已经超过90%的人。**

## 核心原则

> **复习比学新知识更重要**
>
> 不复习 = 忘记 = 白学
