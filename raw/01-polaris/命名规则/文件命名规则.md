# 文件命名规则

## 核心原则

1. **语义清晰** — 文件名要能看懂内容
2. **机器友好** — 无特殊字符，方便搜索
3. **层级分明** — 用 `/` 分隔层级

---

## 02-raw 原始资料

### 结构

```
02-raw/
├── articles/
│   └── YYYY/
│       └── MM/
│           └── YYYY-MM-DD-标题.md
├── papers/
│   └── YYYY/
│       └── MM/
│           └── YYYY-MM-DD-标题.md
└── podcasts/
    └── YYYY/
        └── MM/
            └── YYYY-MM-DD-播客名-集数.md
```

### 规则

| 字段 | 说明 | 格式 |
|------|------|------|
| 年 | 四位年份 | `2026` |
| 月 | 两位月份 | `04` |
| 日 | 两位日期 | `04` |
| 标题 | 核心关键词，英文/中文均可 | `BTC反法币` |

### 示例

```
02-raw/articles/2026/04/2026-04-04-杰文斯悖论.md
02-raw/articles/2026/03/2026-03-28-英伟达GTC2026要点.md
02-raw/papers/2026/04/2026-04-01-Attention-Is-All-You-Need.md
```

### 注意事项

- 标题用核心关键词，不用完整句子
- 多关键词用 `-` 连接：`BTC-经济分析`
- 来源网站可加前缀：`X-Ars-杰文斯悖论`

## 03-wiki 编译产物

### summaries/ 摘要

**结构镜像 raw**：`summaries/` 结构与 `raw/articles/` 完全对应

```
03-wiki/summaries/
└── articles/
    └── YYYY/
        └── MM/
            └── YYYY-MM-DD-标题.md
```

**命名与 raw 完全一致**，仅路径从 `02-raw` 变为 `03-wiki/summaries`

### concepts/ 概念卡片

```
03-wiki/concepts/
├── AI/
│   └── Claude-Code/
│       ├── Agent.md
│       └── MCP.md
├── 投资理财/
│   └── BTC.md
└── 个人成长/
    └── 第一性原理.md
```

| 规则 | 说明 |
|------|------|
| 文件名 | 概念名，`/` 代替空格 |
| 层级 | 不超过 3 层 |
| 命名 | 简短、有辨识度 |

### indexes/ 索引

```
03-wiki/indexes/
├── All-Sources.md
├── All-Concepts.md
└── 术语表.md
```

## 04-outputs 运行时输出

### qa/ 问答沉淀

```
04-outputs/qa/
└── YYYY/
    └── MM/
        └── YYYY-MM-DD-问题关键词.md
```

### health/ 健康检查

```
04-outputs/health/
└── YYYY-MM-DD-健康检查.md
```

## 特殊文件

| 文件 | 命名 |
|------|------|
| CLAUDE.md | 固定名称，不改 |
| 每日笔记 | `YYYY-MM-DD.md` |
| Excalidraw 图 | `描述-日期.excalidraw.md` |

---

## 命名检查清单

- [ ] 无 `#`、`*`、`|` 等特殊字符
- [ ] 无空格，用 `-` 或 `/` 代替
- [ ] 日期格式统一 `YYYY-MM-DD`
- [ ] 标题不超过 50 字符
