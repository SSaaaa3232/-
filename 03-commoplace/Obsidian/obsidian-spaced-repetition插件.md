# obsidian-spaced-repetition 插件

> 来源：https://github.com/st3v3nmw/obsidian-spaced-repetition
> 更新：2026-03-19

---

## 是什么

Obsidian 的**间隔重复复习**插件，基于艾宾浩斯遗忘曲线。

---

## 核心功能

| 功能 | 说明 |
|------|------|
| 闪卡复习 | 像 Anki 一样做卡片 |
| 笔记复习 | 整个笔记设置复习 |
| 统计 | 追踪学习进度 |

---

## 支持的卡片格式

| 格式 | 写法 |
|------|------|
| 问答 | `Question::Answer` |
| 可逆 | `Question:::Answer` |
| 多行 | `?` 分隔 |
| Cloze | `==高亮==` |

---

## 使用方法

1. 安装插件
2. 在笔记中写卡片
3. 标记 `#review` 标签
4. 插件自动安排复习时间

---

## 复习原理

- 复习 → 根据表现 → 自动安排下次复习时间
- 记得牢 → 间隔拉长
- 记不住 → 频繁复习
