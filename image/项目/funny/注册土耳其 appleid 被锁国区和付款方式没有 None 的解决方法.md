本来你兴高采烈的注册好了土耳其区的 apple id ，注册教程在这里：

[2026 年土耳其区 Apple ID 注册教程及避坑指南](https://zhuanlan.zhihu.com/p/2021976845952762095)

按流程来讲，你得先切换一下 App Store 的地区再登录，结果你手快了，直接登录，导致锁在了国区。

然后你想从国区切换回土耳其，但是发现报错“出现错误。请稍后再试”。

接下来的 3 个步骤教你再切换回土耳其：

## 第一步：解决“出现错误。请稍后再试”

（该步骤的完整教程参考 [如何修改 Apple ID 地区？出现错误。请稍后再试。](https://zhuanlan.zhihu.com/p/2030568958005351764#showWechatShareTip) ）

**尽量换到电脑上** ，你需要点击下面的链接 [iCloud 登录](https://www.icloud.com/)

登录 Icloud ，这一个步骤，是证明你这个账号是活跃的。（我猜的）

**换到手机上** ，进入 App Store ，你再更改地区发现可以了， **但是付款方式没有 None 选项** 。

## 第二步（重要）：让你的付款方式出现 None

先杀掉 App Store

把你的小火箭开起来， **全局路由改成“代理”(就是开成全局代理)**

再回去修改就会发现出现 None 选项了。

## 第三步：买礼品卡锁区

（完整教程参考 [国内用户苹果土耳其礼品卡购买全攻略（注册、充值、避坑指南）](https://zblogs.top/apple-turkiye-gift-card-purchase-guide/) ）

当你改回土耳其之后，你需要买礼品卡了，你可以去闲鱼，我是在 mtcgame 买的。购买地址是：

[https://www.mtcgame.com/zh/apple-store/itunes-hediye-karti](https://www.mtcgame.com/zh/apple-store/itunes-hediye-karti)

买完后在你的购买的产品里就能看到兑换码，兑换码的示例是这样

SERIAL=EPY19XXXXXXX - PIN=X9ZXXXXXXXXXX

你需要复制的是 PIN 后面那一段到 App Store 当中进行兑换。
