# 框架

## 自主 Agent 系统

| 工具           | 说明                                                     |
| ------------ | ------------------------------------------------------ |
| **OpenClaw** | 开源 AI agent，多渠道支持（WhatsApp/Telegram/Discord），自写 skills |
| LangGraph    | 多 agent 编排为代码，有分支逻辑、人机交互、持久状态                          |
| CrewAI       | 多 agent 框架，角色+目标+背景故事                                  |
| AutoGPT      | 全自主 agent 平台，长任务运行                                     |
| Dify         | 开源 LLM 应用构建器，工作流+RAG+agent+模型管理                        |
| OWL          | 多 agent 协作框架，GAIA 基准领先                                 |
| CopilotKit   | React 应用内嵌 AI copilot                                  |
| pydantic-ai  | 基于 Pydantic 的类型安全 agent 框架                             |
| Spec Kit     | 规范驱动开发，AI 从规格生成代码                                      |
| Aider        | 终端 AI 结对编程，支持任意 LLM                                    |
| lmnr         | trace 和评估 agent 行为                                     |

| -------------- | ------------------------------- |
| n8n            | 开源工作流自动化，400+ 集成                |

| dlt            | LLM 原生数据管道，5000+ 数据源            |
| ExtractThinker | 文档智能 ORM                        |
| Instructor     | 从任意 LLM 获取结构化 JSON（Pydantic 模型） |
