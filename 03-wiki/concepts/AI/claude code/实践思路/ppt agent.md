	- 到后面再去加设计的效果

		- 设计部分来做风格样式


- 生成整页 SVG 的方案

>SVG：是一种PPT里兼容性最好的格式，
>.          生成的这个SVG代码你可以直接拖到Office 2016以上的版本里去做使用

- 好处：
	- 好处是可以导入 PPT，完全可编辑，甚至各种设计软件都支持，而且可以无限放大，保证清晰度。

# 技巧：

- 便利贴法

- 卡片式布局

	- 好处：

1. **能装：** 一页里能清晰地承载大量信息。
2. **灵活：** 卡片数量、大小、位置可以随意组合，版式变化无穷。
3. **AI能懂：** 这是最关键的！我们发现，“卡片”是AI最容易理解和掌握的一种设计语言
