> 核心原理：反向 WebSocket 隧道 — 你的 Mac 主动连接服务器，不是服务器连接你的 Mac

---

## 安装命令

```bash
curl -fsSL 'https://happycapy.ai/api/bridge/install-script?token=...' | bash
```

- `curl -fsSL <url>` — 从 HappyCapy 服务器下载 shell 脚本
- `| bash` — 把下载的脚本直接交给 bash 执行
- `?token=capy_...` — URL 里的 token 是身份凭证

脚本自动完成：检测系统架构 (arm64)、检查 Node.js、下载 bridge 客户端、安装 CLI 工具、启动后台服务。

---

## 核心架构

```
你的 Mac (本地)          HappyCapy 服务器 (云端)          云端沙箱 (Capy AI)
      |                          |                              |
      |--- WebSocket 主动连接 --->|<--- API 请求 ----------------|
      |                          |                              |
      |<-- 命令下发 --------------|--- 转发 -------------------->|
      |--- 执行结果 ------------>|--- 返回 -------------------->|
```

**关键点：是你的 Mac 主动连接服务器，不是服务器连接你的 Mac**

---

## 为什么能穿透防火墙/NAT？

**WebSocket 长连接的妙处：**

1. 你的 Mac 主动向服务器发起 WebSocket 连接（出方向的连接不受防火墙限制）
2. 这条连接建立后**保持长时间存活**（persistent connection）
3. 服务器通过这条已建立的连接，把命令"推"给你的 Mac
4. 你的 Mac 执行后，把结果通过同一条连接返回

本质：**用一条出方向的长连接，模拟了一个双向通道**

---

## 和 SSH 的对比

| 维度         | SSH               | Mac Bridge (WebSocket 隧道)  |
| ---------- | ----------------- | -------------------------- |
| 连接方向       | 服务器 → 你的 Mac（入方向） | 你的 Mac → 服务器（出方向）          |
| 需要公网 IP    | 是                 | 否                          |
| 穿透 NAT/防火墙 | 通常不行              | 可以                         |
| 端口开放       | 需要开放 22 端口        | 不需要开放任何端口                  |
| 身份验证       | 密钥或密码             | Token（在安装时嵌入）              |
| 协议         | TCP over SSH      | WebSocket over HTTPS (443) |
| 防火墙友好      | 一般                | 极高（走 443 端口，和普通网页一样）       |
| 设置难度       | 需要配置路由器、开端口       | 一条命令搞定                     |

---

## 优势

1. **零网络配置**
   - 不需要公网 IP
   - 不需要路由器端口映射
   - 不需要动防火墙规则

2. **安全性更好**
   - 没有监听端口暴露在公网上（SSH 的 22 端口是常见攻击目标）
   - 全程走 HTTPS/TLS 加密
   - Token 绑定到账号，可以随时撤销

3. **穿透性强**
   - 即使在公司网络、学校网络、出方向的 443 端口通常都开放

4. **一条命令安装**
   - 脚本自动检测环境、下载、配置、注册、启动

---

## Token 的作用

URL 里的 `capy_dXNy...` 是一次性/绑定的安装 token：

- **身份验证**：告诉服务器"这台 Mac 属于哪个用户账号"
- **注册**：服务器给这台 Mac 分配唯一的 `Bridge ID`（如 `br_3198...`）
- **建立关联**：之后 Capy AI 通过这个 Bridge ID 找到你的 Mac 并发送命令

安装完成后，token 作用完成，后续认证靠 Bridge ID 和本地存储的凭证。
