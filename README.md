# Obsidian 个人知识管理系统

> 自动同步 GitHub，AI 增强的第二大脑

---

## 系统架构（PARA）

```
├── 1-项目/      # 正在进行的工作
├── 2-领域/      # 长期关注的领域
├── 3-资源/      # 感兴趣的知识资源
└── 4-系统/      # 规则、模板、系统文件
```
