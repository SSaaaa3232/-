
目标：

把“视频、文字、图片素材”变成可复习、可实践、可迭代的 Anki 注意点系统。

核心原则是：Anki 不是知识仓库，而是注意力训练器；真正要进入 Anki 的不是所有内容，而是以后在学习中必须被召回的注意点。

## 1. 总体闭环

```text
素材输入
  -> AI 粗筛注意点
  -> 你对照原稿/视频做备注
  -> AI 生成终版卡片预览
  -> 你确认
  -> 导入 Anki
  -> 间隔复习
  -> 实践/做题/输出
  -> 发现新坑
  -> 追加新卡
```

这个系统分两层：

1. 日程层：决定每天什么时候输入、什么时候复习、什么时候复盘。
2. Skill 层：用 `/anki` 把素材、备注、新坑稳定加工成卡片。

## 2. 你的日程应该怎么嵌入学习系统

### 上午：输入知识 + 筛选注意点 + 复习旧卡

上午不是只输入，也要安排少量复习。建议结构：

```text
7:30-7:50    Anki 旧卡热身
7:50-11:20   考研主线学习，50+10 循环
每个 50 分钟  只标记卡壳点/错题/混淆点，不做完美整理
每个 10 分钟  快速写下“这个点以后要不要进 Anki”
```

上午的目标不是整理漂亮笔记，而是产出三类材料：

1. 今天必须掌握的新概念。
2. 做题时暴露的错题、卡壳点、混淆点。
3. 值得晚上变成卡片的注意点候选。

### 下午：副线输入 + AI 粗加工

下午的投资、网安、AI、散步缓冲时间，适合做视频学习和材料粗加工：

```text
13:00-14:50  投资/网安轮换学习
14:50-16:20  AI 粗处理、散步消化、补备注
```

这里适合启动 `/anki` 第一阶段：

1. 直接给文字/图片素材。
2. 给视频链接，由 `/anki` 调用 `transcript` 先生成原稿。

下午的目标是拿到：

1. 原稿。
2. 粗版 Anki 候选卡。
3. 原稿内备注模板。

### 晚上：复习卡片 + 优化新坑点

晚上复盘的核心不是大量输入新知识，而是让白天的东西闭环：

```text
18:30-19:20  Anki 复习旧卡
19:20-20:10  根据白天备注优化新卡
20:10-20:40  处理错题/实践新坑
20:40-21:00  确认终版卡片，决定是否导入
```

晚上最重要的产物：

1. 今天新增的终版 Anki 卡。
2. 今天暴露的新坑点卡。
3. 明天需要重点验证的薄弱点。

## 3. “注意点粗稿”是不是 Anki 形式

答案：是“Anki 候选卡形式”，但不是直接导入的终版。

原因：

1. AI 可以先筛出候选注意点，但不能替你决定哪些点真正值得长期复习。
2. 粗稿应该方便你看视频时校准，而不是直接污染 Anki。
3. 真正导入前必须经过你确认。

粗稿格式建议：

```markdown
## 候选卡 001

类型：判断卡
状态：DRAFT
来源：00:03:12-00:04:20

正面：当某个信号只是“接近触发”而不是“正式触发”时，应该怎么处理？

背面：不能无脑执行，要把它当作预警；等待信号确认，再结合小级别窗口找入场位置。

为什么值得复习：这是一个容易从“观察信号”误跳到“立刻操作”的错误。

待你确认：视频里是否强调了具体确认条件？
```

粗稿可以有很多张，但导入 Anki 前需要删、改、合并。

## 4. 原稿内备注：你和 Codex 的“暗号”

你说得对：直接在原稿中备注最好。这样上下文不会丢，也不用另开一份备注。

### 推荐格式

在原稿某段下面直接加一行：

```markdown
> 备注：【暗号】你的话
```

例如：

```markdown
比特币还没有正式触发周线超卖信号，只是接近触发的边缘，所以不能理解成可以无脑抄底。

> 备注：【重】【卡判】接近触发 ≠ 已经触发；问我“这种情况下能不能直接抄底？”
```

### 暗号表

| 暗号 | 含义 | Codex 应该怎么处理 |
|---|---|---|
| 【重】 | 重点 | 保留，优先做卡 |
| 【删】 | 删除 | 不做卡，必要时从粗稿删除 |
| 【错】 | AI 理解错了 | 按你的备注纠正 |
| 【卡概】 | 概念卡 | 做成“是什么/为什么”的卡 |
| 【卡判】 | 判断卡 | 做成“什么情况下怎么判断”的卡 |
| 【卡错】 | 错误卡 | 做成“常见错误/反直觉点”的卡 |
| 【卡填】 | 填空卡 | 做成 cloze/填空题 |
| 【卡选】 | 选择题 | 做成多选/单选，用于辨析 |
| 【坑】 | 实践坑点 | 优先做成错误卡或判断卡 |
| 【例】 | 例子 | 放到背面或 Extra，不单独成卡 |
| 【疑】 | 不确定 | 生成“待确认问题”，不要直接导入 |
| 【合】 | 合并 | 和相邻卡合并 |
| 【改】 | 改写 | 按你的新表述重写卡 |
| 【导】 | 可以导入 | 这条通过你的确认，可进入终版 |

### 最省字的写法

你不需要写完整句子，可以这样：

```markdown
> 备注：【重】【卡判】【导】接近触发不能抄底，要等确认
```

Codex 识别为：

1. 这是重点。
2. 做判断卡。
3. 你已经允许它进入终版候选。
4. 卡片核心是“接近触发不能直接抄底，要等确认”。

### 备注规则

1. 只写在相关原稿段落下面。
2. 一个备注可以有多个暗号。
3. 没有【导】的卡，不自动导入，只进入预览。
4. 有【疑】的卡，必须先问你或放进待确认区。
5. 有【删】的内容，无论 AI 觉得多重要，都不进卡片。

## 5. 最终 Anki 卡片生成和导入规则

最终导入必须分三步：

```text
Codex 生成终版卡片预览
  -> 你确认
  -> Codex 再导入 Anki
```

不能跳过确认。

终版预览格式：

| id | 类型 | 正面 | 背面 | 来源 | 状态 |
|---|---|---|---|---|---|
| 001 | 判断卡 | 当信号只是接近触发时，可以直接抄底吗？ | 不可以。只能当作预警，等待确认。 | 视频 00:03:12 | 待确认 |

你确认时可以说：

```text
确认导入 001-020
删除 003 008
修改 006：把“抄底”改成“开仓”
```

导入方式分两级：

1. 第一版：生成 `.csv` 或 `.tsv`，你确认后手动导入 Anki。
2. 稳定后：用 AnkiConnect 自动导入本机 Anki，但仍然先给你预览确认。

自动导入需要本机 Anki 已打开，并安装 AnkiConnect。AnkiConnect 会在本机 `127.0.0.1:8765` 提供 API；这适合后续自动导入，但不是第一版必须依赖。

## 6. 卡片类型说明

### 概念卡

用途：记“是什么”。

适合：

1. 考研概念。
2. 网安术语。
3. 投资指标定义。

例子：

```text
正面：什么是周线级别超卖信号？
背面：它表示在周线尺度上价格进入相对过度下跌区域，历史上容易出现反弹窗口，但不等于必然大底。
```

### 判断卡

用途：训练真实场景下怎么判断。

这是你的核心卡型。

例子：

```text
正面：当周线超卖信号只是接近触发，还没有正式触发时，应该怎么处理？
背面：只把它当成预警，不无脑抄底；继续观察正式触发时间，并结合小级别信号找入场。
```

### 错误卡

用途：防止重复踩坑。

例子：

```text
正面：看到“接近触发周线超卖”就直接重仓抄底，错在哪里？
背面：把预警当成确认信号；缺少小级别入场、止损和仓位设计。
```

### 填空卡

用途：记关键条件、步骤、公式、阈值。

Anki Cloze 格式类似：

```text
当信号只是{{c1::接近触发}}而不是{{c2::正式触发}}时，只能当作预警。
```

### 选择题

用途：辨析多个相似条件。

少量使用。选择题写太多会变成“认选项”，不如判断卡扎实。

## 8. 间隔复习和遗忘曲线说明

Anki 的核心不是“每天重复看”，而是在你快忘的时候安排复习。现代 Anki 支持 FSRS；FSRS 会根据你的复习历史估计每张卡的记忆状态，包括可回忆概率、稳定度和难度。保留率设得越高，每天复习量越大。

复习按钮可以这样理解：

| 按钮 | 你什么时候按 |
|---|---|
| Again | 完全想不起来，或答错关键点 |
| Hard | 想起来了，但很吃力/不完整 |
| Good | 正常想起核心答案 |
| Easy | 秒想起，而且非常稳 |

你的使用规则：

1. 不要为了减少复习量乱按 Easy。
2. 判断卡如果答对结论但说不出原因，按 Hard。
3. 错误卡如果又踩同样坑，按 Again。
4. 新卡太多时，先停新增，清旧卡 backlog。
5. 每晚复盘新增卡时，控制数量，宁可 10 张好卡，不要 60 张垃圾卡。

建议初始节奏：

```text
上午：10-20 分钟旧卡热身
晚上：40-60 分钟旧卡复习
晚上：新增 10-30 张高质量新卡
周末：清理低质量卡、合并重复卡、补实践坑点
```

## 9. `/anki` skill 设计

你希望用 `nskill` 新建一个 skill，名字叫 `anki`。建议这是一个上层学习闭环 skill，不替代 `transcript`。

### 激活方式

```text
/anki 视频链接
/anki 这些文字帮我变成注意点粗稿
/anki refine 这是我在原稿里的备注
/anki 新坑：我今天实践发现……
```

### 第一阶段：素材 -> 原稿/粗稿/备注模板

两种情况：

#### 情况 A：直接给文字、图片素材

输入：

```text
/anki
主题：考研/投资/网安
素材：文字或图片
目标：生成粗版注意点
```

输出：

1. `source.md`：整理后的原素材。
2. `draft-cards.md`：候选 Anki 卡。
3. `annotated-source.md`：带备注槽的原稿。

#### 情况 B：给视频

输入：

```text
/anki 视频链接
主题：投资
```

流程：

1. 调用 `transcript` 生成原稿。
2. 基于原稿生成候选 Anki 卡。
3. 在原稿里插入备注模板。

输出：

1. 完整原稿。
2. 粗版候选卡。
3. 可备注原稿。

### 第二阶段：备注/新坑 -> 终版卡片

#### 情况 A：你备注完原稿

输入：

```text
/anki refine
这是我备注后的原稿：...
```

流程：

1. 读取你的暗号。
2. 删除【删】。
3. 修正【错】。
4. 优先处理【重】【导】。
5. 将【卡概】【卡判】【卡错】【卡填】【卡选】转成对应卡型。
6. 生成终版预览。
7. 等你确认。
8. 再导入 Anki 或生成导入文件。

#### 情况 B：复盘发现新坑

输入：

```text
/anki 新坑
主题：投资
我今天犯的错：看到信号接近触发就提前开仓。
正确做法：等确认后再结合小级别入场。
```

输出：

1. 错误卡。
2. 判断卡。
3. 必要时追加一个行动规则卡。

## 10. 交付文件命名建议

每次学习任务生成一个文件夹：

```text
anki/YYYY-MM-DD-主题-来源/
  source.md
  annotated-source.md
  draft-cards.md
  final-cards-preview.md
  import.tsv
```

规则：

1. `source.md` 保留原稿。
2. `annotated-source.md` 给你备注。
3. `draft-cards.md` 是 AI 粗筛。
4. `final-cards-preview.md` 是导入前预览。
5. `import.tsv` 只有你确认后才生成或导入。

6. 能在你确认后生成终版卡片。
7. 能把复盘新坑直接变成卡。
8. 能输出适合 Anki 导入的 `.tsv`。
