
目标：

把“视频、文字、图片素材”变成可复习、可实践、可迭代的 Anki 注意点系统。

核心原则是：Anki 不是知识仓库，而是注意力训练器；真正要进入 Anki 的不是所有内容，而是以后在学习中必须被召回的注意点。


## 总体闭环

```text
素材输入
  -> AI 粗筛注意点
  -> 你对照原稿/视频做备注
  -> AI 生成终版卡片预览
  -> 你确认
  -> 导入 Anki
  -> 间隔复习
  -> 实践/做题/输出
  -> 发现新坑
  -> 追加新卡
```


## 间隔复习和遗忘曲线说明

Anki 的核心不是“每天重复看”，而是在你快忘的时候安排复习。现代 Anki 支持 FSRS；FSRS 会根据你的复习历史估计每张卡的记忆状态，包括可回忆概率、稳定度和难度。保留率设得越高，每天复习量越大。

复习按钮可以这样理解：

| 按钮 | 你什么时候按 |
|---|---|
| Again | 完全想不起来，或答错关键点 |
| Hard | 想起来了，但很吃力/不完整 |
| Good | 正常想起核心答案 |
| Easy | 秒想起，而且非常稳 |

你的使用规则：

1. 不要为了减少复习量乱按 Easy。
2. 判断卡如果答对结论但说不出原因，按 Hard。
3. 错误卡如果又踩同样坑，按 Again。
4. 新卡太多时，先停新增，清旧卡 backlog。
5. 每晚复盘新增卡时，控制数量，宁可 10 张好卡，不要 60 张垃圾卡。
