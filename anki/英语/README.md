# 英语

这是 Anki 软件中「英语」牌组的本地镜像，用于在 Obsidian 中保留素材、候选粗卡和导出前的可审阅版本；它不会自行修改或导入 Anki。

## 工作流

素材 -> 候选粗卡 -> 用户修改 -> AI 在原文件中优化 -> 仅在用户明确确认后生成该牌组唯一的 TSV -> 用户决定是否导入

## 收录优先级

优先把真实错误、卡住点和混淆点转成候选卡。可查询的背景知识留在 `notes/`，不因“可能有用”而制卡。

## 目录

- `templates/`：六种候选卡模板。
- `notes/`：素材、转写、上下文与可查询背景。
- `cards/`：只有用户明确确认后才可生成该牌组唯一的 TSV；是否导入由用户决定。
