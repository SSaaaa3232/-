# Sub2API

GitHub 上有个项目叫 Sub2API，六千多 star，开源的。干的事儿说白了就是把你买的 Claude、OpenAI、Gemini 订阅，变成标准 API 接口，然后你想自己用也行，卖给别人也行。

多账号管理、Key 分发、按 Token 计费、自动调度——该有的都有。

搭起来不难

**一键装：**

bashcurl -sSL [https://raw.githubusercontent.com/Wei-Shaw/sub2api/main/deploy/install.sh](https://raw.githubusercontent.com/Wei-Shaw/sub2api/main/deploy/install.sh) | sudo bash

装完浏览器打开 http://你的IP:8080，跟着向导走就行。

**或者用 Docker：**

bashgit clone [https://github.com/Wei-Shaw/sub2api.git](https://github.com/Wei-Shaw/sub2api.git) cd sub2api/deploy docker-compose up -d

五分钟能跑起来。

装好之后就四步：把你的订阅账号加进去，设好单价，生成 API Key，给客户用。完事。

说说利润空间。Claude Max 订阅 $200 一个月，理论上反代出来大概值 $2400 的 API 调用。12 倍杠杆。当然你跑不满，实际利用率三到六成，一个号一个月你赚几百到一千块是正常的。多搞几个号，你自己算。

# 生意

## 第一步：别急着卖，先自己用

拉上三五个朋友，一起分摊一个 Claude Max。每个人成本降七成。你在这个过程中把系统摸熟，哪里容易出问题、怎么管账号、怎么控制用量——先趟一遍。

很多人跳过这步，直接开卖，然后被客户的各种问题搞得焦头烂额。你连自己的系统都没摸透就去伺候别人，那不是创业，那是找罪受。

## 第二步：小红书、闲鱼小范围卖

包月卡，定价 200 到 300。别再往下了，再低你覆盖不了时间成本。

小红书上重要的不是标题多炸裂，是让人觉得你靠谱。放点使用截图，放点响应速度测试，让人知道你在认真做这件事，不是那种随时要跑路的人。

闲鱼就靠搜索词，"Claude API""GPT 代理"这些词有人搜。

做到十到三十个稳定客户，月入两三千到小一万，不夸张，但得一两个月的沉淀。

## 第三步：接企业

B 端才是大头。一个企业客户顶二十个个人客户，不墨迹，不扯皮，量大稳定。

但你得有公司、能开票、服务别断。这不是你第一天能干的事。先把前两步走扎实再说。

## 这行的坑，我一个不落地踩过

# 封号

Anthropic 现在封杀越来越狠。请求体指纹、Machine ID 追踪、GA3 指纹检测全都上了。不是你会不会被封的问题，是早晚的问题。

多号轮换、控制单号调用频率、分散在不同机器上——能续命，但不能根治。这是这行最大的底层风险。你得时刻做好某天醒来发现号全没了的准备。

# 售后成本

售后成本是看不见的成本。很多人算利润只算差价，不算自己每天花两三个小时回消息的那部分命。

做个 FAQ、搞个自助查余额页面，能自动化的全自动化。不然你就是给自己找了个月薪三千的客服工作。

# 价格战，而且你打不赢

有人卖一刀一块钱人民币。你走合规渠道成本最低也是一刀六块五。你怎么打？

不打。

卖低价的要么是灰色渠道，要么是烧号跑量，要么纯粹是亏钱换用户后面割。你跟他们拼价格就是找死。

你只能找愿意为稳定多花点钱的客户。这种人有，但你得筛，不能来者不拒。

# 合规

《生成式 AI 服务管理暂行办法》摆在那里。2026 年 4 月国家安全部专门就 Token 交易发了安全警示。这个口子在收紧。

不是说明天就查到你头上，但趋势在这。低调做，别搞大张旗鼓的公开推广，别用真名实姓去搞高调营销。


# 没有技术壁垒

Sub2API 是开源的。今天你搭了，明天你对面那哥们也能搭一个一模一样的，然后比你便宜两块钱把你客户全挖走。

技术不是护城河。唯一的护城河是客户信不信你、愿不愿意长期用你。这个东西需要时间和口碑，复制不了。

# 己搭和跟别人混，差别在哪

自己搭 Sub2API跟代理体系混数据在你自己服务器上在别人服务器上定价你说了算上面给你定底价利润全归你被抽一层又一层成本一年一百多块的服务器代理费、培训费、各种费风险清清楚楚，自己扛上面出事你跟着倒霉本质你是老板你是打工的，只是以为自己在创业
